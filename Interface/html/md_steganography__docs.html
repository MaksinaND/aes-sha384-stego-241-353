Документация по использованию функций стеганографии

Общее описание

Модуль стеганографии предоставляет функции для внедрения и извлечения сообщений из изображений с использованием метода LSB (Least Significant Bit). Перед внедрением сообщение шифруется с использованием алгоритма AES-256, а для проверки целостности используется хеш SHA-384.

Класс Steganography

Класс Steganography является основным классом для работы со стеганографией. Он предоставляет методы для внедрения и извлечения сообщений из изображений.

Внедрение сообщения в изображение

QImage embedMessage(const QImage &image, const QString &message, const QString &password);

Внедряет сообщение в изображение с использованием метода LSB.

Параметры:

  • image - Исходное изображение
  • message - Сообщение для внедрения
  • password - Пароль для шифрования сообщения

Возвращаемое значение:

  • Изображение с внедренным сообщением или пустое изображение в случае ошибки

Пример использования:

Steganography stego;
QImage originalImage("path/to/image.png");
QString message = "Секретное сообщение";
QString password = "password123";
QImage stegoImage = stego.embedMessage(originalImage, message, password);
if (!stegoImage.isNull()) {
stegoImage.save("path/to/stego_image.png");
} else {
qDebug() << "Ошибка при внедрении сообщения:" << stego.lastError();
}

Интеграция с интерфейсом

Для интеграции функций стеганографии с интерфейсом приложения были добавлены следующие элементы:

  1. Кнопки для выбора изображений
  2. Поля для ввода сообщения и пароля
  3. Кнопки для внедрения и извлечения сообщений
  4. Кнопка для сохранения изображения с внедренным сообщением

Внедрение сообщения

  1. Нажмите кнопку "Выбрать изображение" в разделе "Внедрение"
  2. Выберите изображение, в которое нужно внедрить сообщение
  3. Введите сообщение в поле ввода
  4. Введите пароль в поле ввода пароля
  5. Нажмите кнопку "Внедрить"
  6. После успешного внедрения нажмите кнопку "Сохранить изображение" для сохранения результата

Извлечение сообщения

  1. Нажмите кнопку "Выбрать изображение" в разделе "Извлечение"
  2. Выберите изображение, из которого нужно извлечь сообщение
  3. Введите пароль в поле ввода пароля
  4. Нажмите кнопку "Извлечь"
  5. Извлеченное сообщение будет отображено в текстовом поле

Ограничения и рекомендации

  1. Для внедрения сообщений рекомендуется использовать изображения в форматах PNG или BMP, так как они не используют сжатие с потерями.
  2. Максимальный размер сообщения зависит от размера изображения. Для изображения размером 512x512 пикселей максимальный размер сообщения составляет примерно 98 КБ.
  3. Пароль должен быть достаточно сложным для обеспечения безопасности шифрования.
  4. При сохранении изображения с внедренным сообщением рекомендуется использовать формат PNG для предотвращения потери данных.
  5. Внедрение сообщения в изображение может незначительно изменить его визуальные характеристики, но эти изменения обычно не заметны для человеческого глаза.

Технические детали

Алгоритм внедрения сообщения

  1. Сообщение шифруется с использованием алгоритма AES-256 с ключом, полученным из пароля.
  2. Вычисляется хеш SHA-384 зашифрованного сообщения для проверки целостности.
  3. В начало изображения внедряется сигнатура "STEGA" для идентификации наличия внедренного сообщения.
  4. Затем внедряется размер данных (4 байта).
  5. После этого внедряются зашифрованные данные и хеш.
  6. Для внедрения используется метод LSB, при котором каждый бит данных внедряется в младший бит цветового канала пикселя.

Алгоритм извлечения сообщения

  1. Проверяется наличие сигнатуры "STEGA" в начале изображения.
  2. Извлекается размер данных (4 байта).
  3. Извлекаются зашифрованные данные и хеш.
  4. Проверяется целостность данных путем сравнения извлеченного хеша с вычисленным хешем.
  5. Данные дешифруются с использованием алгоритма AES-256 с ключом, полученным из пароля.
  6. Возвращается дешифрованное сообщение.

Заключение

Модуль стеганографии предоставляет простой и безопасный способ внедрения и извлечения сообщений из изображений. Он может быть использован для скрытой передачи информации или для защиты авторских прав на изображения.
