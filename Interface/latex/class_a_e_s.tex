\doxysubsection{Detailed Description}
Класс \doxylink{class_a_e_s}{AES} реализует алгоритм шифрования Advanced Encryption Standard. 

Эта реализация поддерживает ключи длиной 128, 192 и 256 бит. Режим работы -\/ ECB (Electronic Codebook).
