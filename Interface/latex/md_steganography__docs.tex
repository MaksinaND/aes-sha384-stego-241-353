Модуль стеганографии предоставляет функции для внедрения и извлечения сообщений из изображений с использованием метода LSB (Least Significant Bit). Перед внедрением сообщение шифруется с использованием алгоритма AES-\/256, а для проверки целостности используется хеш SHA-\/384.\hypertarget{md_steganography__docs_autotoc_md2}{}\doxysection{\texorpdfstring{Класс Steganography}{Класс Steganography}}\label{md_steganography__docs_autotoc_md2}

\end{DoxyEnumerate}\hypertarget{md_steganography__docs_autotoc_md12}{}\doxysection{\texorpdfstring{Ограничения и рекомендации}{Ограничения и рекомендации}}\label{md_steganography__docs_autotoc_md12}

\begin{DoxyEnumerate}
\item Для внедрения сообщений рекомендуется использовать изображения в форматах PNG или BMP, так как они не используют сжатие с потерями.
\item Максимальный размер сообщения зависит от размера изображения. Для изображения размером 512x512 пикселей максимальный размер сообщения составляет примерно 98 КБ.
\item Пароль должен быть достаточно сложным для обеспечения безопасности шифрования.
\item При сохранении изображения с внедренным сообщением рекомендуется использовать формат PNG для предотвращения потери данных.
\item Внедрение сообщения в изображение может незначительно изменить его визуальные характеристики, но эти изменения обычно не заметны для человеческого глаза.
\end{DoxyEnumerate}\hypertarget{md_steganography__docs_autotoc_md13}{}\doxysection{\texorpdfstring{Технические детали}{Технические детали}}\label{md_steganography__docs_autotoc_md13}
\hypertarget{md_steganography__docs_autotoc_md14}{}\doxysubsection{\texorpdfstring{Алгоритм внедрения сообщения}{Алгоритм внедрения сообщения}}\label{md_steganography__docs_autotoc_md14}

\begin{DoxyEnumerate}
\item Сообщение шифруется с использованием алгоритма AES-\/256 с ключом, полученным из пароля.
\item Вычисляется хеш SHA-\/384 зашифрованного сообщения для проверки целостности.
\item В начало изображения внедряется сигнатура "{}\+STEGA"{} для идентификации наличия внедренного сообщения.
\item Затем внедряется размер данных (4 байта).
\item После этого внедряются зашифрованные данные и хеш.
\item Для внедрения используется метод LSB, при котором каждый бит данных внедряется в младший бит цветового канала пикселя.
\end{DoxyEnumerate}\hypertarget{md_steganography__docs_autotoc_md15}{}\doxysubsection{\texorpdfstring{Алгоритм извлечения сообщения}{Алгоритм извлечения сообщения}}\label{md_steganography__docs_autotoc_md15}

\begin{DoxyEnumerate}
\item Проверяется наличие сигнатуры "{}\+STEGA"{} в начале изображения.
\item Извлекается размер данных (4 байта).
\item Извлекаются зашифрованные данные и хеш.
\item Проверяется целостность данных путем сравнения извлеченного хеша с вычисленным хешем.
\item Данные дешифруются с использованием алгоритма AES-\/256 с ключом, полученным из пароля.
\item Возвращается дешифрованное сообщение.
\end{DoxyEnumerate}\hypertarget{md_steganography__docs_autotoc_md16}{}\doxysection{\texorpdfstring{Заключение}{Заключение}}\label{md_steganography__docs_autotoc_md16}
Модуль стеганографии предоставляет простой и безопасный способ внедрения и извлечения сообщений из изображений. Он может быть использован для скрытой передачи информации или для защиты авторских прав на изображения.
